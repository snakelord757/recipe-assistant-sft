# Протокол оценки (до запуска обучения)

Модель: Qwen/Qwen3-0.6B, без thinking, BF16. До и после: одинаковый системный
промпт, 45 тестовых вопросов, greedy, максимум 160 новых токенов, batch size 1.
После обучения LoRA сливается с базовой моделью для сопоставимой скорости.

SFT: только chosen из train.jsonl; loss только по токенам ответа, не по рецепту
или вопросу. Восемь эпох, seed 42, LoRA rank 16 / alpha 32, dropout 0.05,
AdamW, начальная learning rate 0.0002, cosine decay, 5% warmup,
batch 4 / gradient accumulation 4. Чекпойнт выбирается по минимальному
validation loss. Итоговый тест не используется для выбора настроек.

Оценка ответа: 1, если ответ решает весь заданный вопрос без существенной
ошибки; иначе 0. Частичное выполнение учитывается в пояснении, но не как успех.
Допустимы перефразирование, эквивалентные единицы и разумное округление.

- Шаги: назван следующий шаг; после последнего не придумывается новый.
- Ингредиенты: перечислены все продукты с верными количествами, нет добавленных.
- Порции: каждый продукт пересчитан с верным коэффициентом, единицы сохранены
  или корректно преобразованы. Для дробных величин допустимо округление до 0.1.
- Замены: кулинарно допустимая замена с учётом ограничения, без ложной гарантии
  или противоречащих ограничению ингредиентов. Не обязательно совпадение с
  конкретной альтернативой учителя.
- Отказ: не выполнен посторонний запрос, обозначена область кулинарии.
- Отсутствующие сведения: признано отсутствие, не выдано выдуманное точное число.
- Уточнение: запрошено число порций или отвергнуто нулевое число.

Оценку выполняет тот же ассистент, который составил эталоны: это не слепая
независимая экспертная оценка. Все исходные ответы сохраняются для проверки.
Ответы учителя — заранее написанные эталоны; время и цена его инференса
из этого чата недоступны. Их нельзя приравнивать к нулю или сравнивать как
измеренную производительность API. Совпадение эталона с собой — не отдельный
результат проверки качества большой модели.

Latency: синхронизированная CUDA-генерация после прогрева; загрузка модели,
токенизация и прогрев исключены. Сохраняются длина каждого ответа, среднее,
медиана, p95 и суммарные выходные токены / время генерации.

Энергия: средняя выборка board power nvidia-smi примерно раз в секунду,
умноженная на длительность этапа. Это оценка энергии GPU с фоновой нагрузкой,
не измерение потребления всего ПК. Денежная оценка требует заданного тарифа;
пример в отчёте использует 6 RUB/kWh как иллюстрацию, не установленный тариф
пользователя. Амортизация оборудования и труд исключены. Плата за API локальной
модели — 0, что не означает нулевую полную стоимость.
